# DERD v1.9 release notes

## Phase 19: blind external-group replay kit

### Added

- seven opaque replication tasks, comprising four synthetic photometry controls and three blinded observational harmonic-exchange controls;
- a public wheel-based execution kit with checksums, container recipe, task seal, protocol seal, and submission schema;
- a separately packaged private evaluator and HMAC-SHA256 answer commitment;
- deterministic signed-harmonic extraction, recurrence screening, covariance propagation, and direct DERD-G/DERD-K control outputs;
- an internal clean-room packaging control;
- claims C91 through C96 and updated OURD, IURMv1.1.1, EDOv1, ledger, and reproducibility graph objects.

### Result

The local isolated-process control reproduced all seven committed scientific projections. No external operator submission has yet been received or verified.

### Scope

This release makes external computational replication executable. It does not itself constitute external replication, independent observing evidence, population validation, or evidence for a transparent shell or shell mass.
