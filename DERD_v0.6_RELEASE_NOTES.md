- claims C29 through C33.

## Changed

Relative phase conversion is now blocked by default in `catalog_harmonics.py`. It can be re-enabled only with `allow_unsafe_relative=True`, which is intended for non-evidentiary exploratory work.

## Scientific decision

The discovered legacy feature tables are not accepted as exact complex-harmonic evidence. The result does not reject DERD. It rejects an information-losing and incompletely reproduced transport format as a proof substrate.
